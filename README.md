# Conversor-de-.ris-a-.xlsx
Script en python que convierte archivos .ris a .xlsx
---
### Para ejecutar el archivo
```python
py convert-ris-to-excel.py
```

### Ingresa el nombre de tu archivo .ris con la extensión
Ingresa el nombre del archivo RIS: example.ris <br>
_(Si olvidas la extensión del archivo .ris el código lo añadirá por ti.)_

### Ingresa el nombre del archivo en el que vas a guardar la tabla de artículos creada
Ingresa el nombre del archivo Excel que almacenará los artículos: example_articles <br>
_(Si te olvidas de la extensión .xlsx el código lo añadirá por ti.)_

### Si la conversión se realizó con éxito verás mensajes como los siguientes:
Archivo detectado. Iniciando la conversión de 'example.ris'... <br>
Procesamiento exitoso. 56 artículos exportados a example_articles.xlsx <br>
Proceso finalizado. Puedes revisar tu Excel en el explorador de archivos.

### De lo contrario podrías ver mensajes de error como los siguientes:
No se pudo encontrar el archivo 'example'.
o
Verifica que el nombre sea correcto y que esté en el directorio adecuado.
